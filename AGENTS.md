## Jerarquía de instrucciones de producto y diseño

Para cualquier tarea en este repositorio, aplica esta prioridad:

1. La instrucción explícita del usuario para la tarea actual.
2. PRODUCT.md y DESIGN.md como fuente de verdad del producto, identidad visual y decisiones de marca.
3. Reglas existentes de arquitectura, accesibilidad, seguridad y convenciones propias del repositorio.
4. Skills especializados instalados, incluidos Impeccable, GSAP y design-taste-frontend.

Los skills deben complementar el sistema existente, no reemplazarlo.

Si una recomendación de un skill contradice PRODUCT.md o DESIGN.md, conserva la decisión definida por el proyecto salvo que el usuario autorice explícitamente explorar o cambiar esa decisión.

Los defaults tecnológicos o estéticos de un skill no justifican por sí solos:
- migrar el stack tecnológico;
- cambiar la paleta de marca;
- cambiar tipografías;
- modificar branding;
- sustituir la arquitectura existente;
- introducir nuevas dependencias o frameworks.

Los skills pueden proponer mejoras y señalar oportunidades, pero deben adaptarse a UniversoVet y a sus restricciones existentes.
